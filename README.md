
# Registration System

A full-stack registration application built with HTML, CSS, JavaScript, Node.js, Express.js and MySQL.

## Features
- User registration
- MySQL database integration
- Admin login and dashboard
- Backend API integration

## Tech Stack
- HTML, CSS, JavaScript
- Node.js and Express.js
- MySQL

## Setup
1. Install Node.js and MySQL.
2. Configure your local environment variables using `.env.example`.
3. Install dependencies with `npm install`.
4. Start the backend using the project's configured npm development script.
5. Open the frontend through a local development server.

## Security
Do not commit `.env` files, passwords, session secrets or real user data.
